Programmatic SEO at the edge.

A self-hosted toolkit that publishes one AI-written blog post a day and turns a keyword list into hundreds of indexable landing pages. Runs entirely on Cloudflare — Pages Functions, D1, R2, Workers AI. Free tier covers most use cases.

⭐ Star on GitHub See the blog

One post a day, on autopilot

A daily cron picks a topic from a 50-entry pool, generates a 900-1300 word post with a hero image, and pings IndexNow. Three backup windows resume failed jobs the same day.

Programmatic landing pages

Drop a CSV of long-tail keywords. The worker chews through them one at a time, producing a unique 700-1000 word landing page per keyword — each with its own schema, sitemap entry, and IndexNow ping.

Workers AI primary, OpenAI fallback

Defaults to Llama 3.3 70B + Flux on Workers AI — free at the edge. Configure an OpenAI key and posts can opt-in to gpt-5 + gpt-image-1 for higher quality.

Drop-in widget for any site

One-line <script> tag puts your latest posts on your existing marketing site. Cross-origin enabled, zero-CSS footprint.

SEO plumbing included

Dynamic sitemap, robots.txt, canonical URLs, Open Graph, JSON-LD Article + BreadcrumbList schema, automatic IndexNow on publish. The boring stuff is already done.

Resilient by design

Multi-step generation chain (topic → article → image → publish) with a draft state between each step. A transient OpenAI error doesn't lose the post — the next cron resumes from the failed step.

Five-minute setup

git clone https://github.com/Benjamin-Bloch/pages-seo
cd pages-seo
wrangler d1 create pages-seo
wrangler r2 bucket create pages-seo-images
wrangler pages secret put ADMIN_TOKEN --project-name=pages-seo
wrangler pages secret put INDEXNOW_KEY --project-name=pages-seo
npm run db:init
npm run deploy
