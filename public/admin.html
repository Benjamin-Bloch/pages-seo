    Layered on top of every LLM prompt. Tell the model who's writing and who's reading — output quality jumps immediately. Leave any field blank to use the built-in default.

    Budget
    
        
    Monthly AI spend cap
    
        
    The cron Worker hard-stops once monthly spend reaches the limit. Manual admin generations keep working but you'll see a warning banner. Set to 0 to disable.
    
        
    
          
          
        
    
      
    
      
    
        
    Pricing
    
        
    LLM rate catalogue
    
        
    Token costs are pulled from models.dev, a community-maintained catalogue of LLM prices. Falls back to a bundled snapshot if the network call fails.
    
        
    
          
          
        
    
        
    Loading current rates…
    
      
    
      
    
        
    Length
    
        
    Post length targets
    
        
    Hints to the model. Workers AI tends to undershoot; cloud models hit these reliably.
    
        
    
          
          
          
          
        
    
      
    
      
    
        
    Provider
    
        
    Preferred AI provider
    
        
    The toolkit tries this provider first for every job. If it fails, the rest of the configured providers are tried in registry order. Leave blank to use the default (Workers AI).
    
        
      
    
      
    
        
    Internal link aliases
    
        
    URLs the LLM can reference by name
    
        
    When the model writes [Sign up](signup) it gets expanded to your signup URL. Useful if your signup/pricing/contact pages live at non-standard paths.
