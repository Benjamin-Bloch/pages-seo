Install pages-seo on your Cloudflare account

Install pages-seo.

We'll provision a Pages project, a D1 database, an R2 bucket, and the Workers AI binding — all on your Cloudflare account. You'll get a working site at the end with the admin already seeded.

Recommended: install from your terminal in one command (~2 min):

npx pages-seo-install

Uses wrangler login (browser OAuth), no API token to copy. Works with Node 20+. Read more →

Or install in your browser (requires the Cloudflare Pages GitHub App)

The browser installer below uses an API token and creates a Pages project linked to the public pages-seo GitHub repo. Cloudflare requires you to install their Workers & Pages GitHub App on your account before the linkage works — which is an extra step the CLI flow avoids.

Hit a snag.

—

Cloudflare needs one-time access to GitHub. Pages can't see your repo until the Cloudflare Workers & Pages GitHub App is authorised on your account.

Fastest fix:

  1. Install GitHub App → (opens in a new tab)
  2. Grant access to your pages-seo fork (or "All repositories" if you prefer).
  3. Come back here and hit Resume install.

Alternative: visit Cloudflare → Workers & Pages → Create → Pages → Connect to Git and authorise from there.

Your progress is saved. Hitting Resume picks up from the step that failed — already-created resources are reused, not recreated.
