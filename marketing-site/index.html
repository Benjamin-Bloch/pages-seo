How it works

Four phases — set up once, then it runs on its own.

  1. Install

    One command (bash setup.sh) provisions a Cloudflare Pages project, a D1 database, an R2 bucket, applies the schema, pushes secrets and deploys. Every step writes to .setup-state; if any step fails (network, auth, quota), just re-run and it resumes from the failure.

  2. Generate

    A scheduled Cloudflare Worker calls a four-step chain — pick topic → write text → render hero image → publish — with each step idempotent and short enough to fit Cloudflare's request budget. Survives Pages Functions' aggressive isolate kills.

  3. Distribute

    New posts appear in /sitemap.xml immediately. IndexNow pings Bing, Yandex and Seznam on every publish. Google picks them up via the sitemap. The RSS feed exposes posts to readers and aggregators.

  4. Iterate

    The admin dashboard tracks your queue, published pages, jobs in flight, and per-provider statistics. A dry-run endpoint lets you preview AI output (with full HTML rendering) before it ever touches your database.

The stack

Every component runs on Cloudflare, except the LLM call (your choice).

Cloudflare Pages

Serves the public site, blog, programmatic pages, sitemap, robots.txt and the admin SPA. File-based routing through functions/.

D1 (SQLite at the edge)

Stores generated posts, programmatic pages, the keyword queue, job state, and an audit log. Six tables; ~50 lines of SQL.

R2 (object storage)

Hero images. Served via a Pages Function that sets immutable cache headers — Cloudflare's CDN handles repeat fetches.

Workers AI

Default text + image generation. Llama 3.3 70B for text, Flux 1 schnell for images. Free tier covers most use cases.

Scheduled Worker

Separate Worker that calls the admin API on cron triggers. Drives the daily blog at 08:00 UTC, retries at 10/14/18:00.

Optional LLM keys

OpenAI · Anthropic · Gemini · Groq · DeepSeek · Mistral · Together · Cerebras. Drop in a key and it joins the fallback chain.

Install

One command. Resumable. Setup script auto-installs wrangler and runs wrangler login for you if needed.

# 1. clone the repo
git clone https://github.com/Benjamin-Bloch/pages-seo
cd pages-seo

# 2. run any of the three flavours
bash setup.sh        # or: python3 setup.py · node setup.js

# 3. paste the printed ADMIN_TOKEN at /admin
open https://<your-site>.pages.dev/admin

The script asks for a project name, your domain, and (optionally) keys for any of the nine AI providers. It generates an admin token, creates the Cloudflare resources, applies the schema, pushes secrets, and deploys. If a step fails, just re-run — it picks up from where it left off.

FAQ

How much does it actually cost to run?

On Cloudflare's free tier with Workers AI as the LLM: $0/month, until you exceed the free quotas (~10k Workers AI requests/day, 100k Pages requests/day, 5GB D1 storage). Past that you're on Workers Paid ($5/month) plus single-digit cents per million additional operations.

Do I have to use Workers AI?

No. It's the default because the free tier makes it the lowest-friction option, but you can route everything through OpenAI, Anthropic Claude, Google Gemini, Groq, DeepSeek, Mistral, Together AI, or Cerebras. Set the API key as a Pages secret and it joins the fallback chain in registry order. Adding a tenth provider is one entry in functions/_lib/ai.js.

How good is the generated content?

Workers AI (Llama 3.3 70B) produces SEO-coherent, structurally clean copy — title, meta, slug, keywords, H2/H3, FAQ, CTA all in place. The prose is generic. For higher-quality output, plug in Claude or GPT-5 — same toolkit, same workflow, just different output quality.

Will search engines penalise AI content?

Google's published position is that AI content is fine if it's useful. The toolkit ships with the SEO essentials baked in: Article + Breadcrumb schema, structured headings, FAQ blocks, primary/secondary keyword targeting, IndexNow pings, canonical URLs. Quality is on the model you choose.

Can I edit posts manually?

Yes. Posts live in your D1 database — edit via the admin UI's post detail view, or run SQL directly with wrangler d1 execute. Hero images live in R2; replace by uploading a new file with the same key.

Is the admin dashboard secure?

Bearer-token auth with a 64-char hex token generated at install. Stored as a Cloudflare Pages secret on the server, in localStorage on your machine. No accounts, no sessions, no password reset flow. Rotate the token via wrangler pages secret put ADMIN_TOKEN if it leaks.
