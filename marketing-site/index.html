pages-seo is an open-source toolkit that runs a programmatic-SEO machine on Cloudflare Pages — daily blog generation, keyword-driven landing pages, sitemap, IndexNow, RSS, embeddable widget. Five-minute install. Free tier covers it.

What you get

Daily AI blog

One SEO-optimised post a day, with a hero image. Multi-step generation chain that survives Cloudflare's edge timeout. Resumable if it fails halfway.

Programmatic pages

Feed it a keyword list (or pull keywords automatically from Google Autocomplete) and it generates one ranked landing page per keyword.

9 AI providers

Workers AI (free tier) by default. Drop in keys for OpenAI, Anthropic, Gemini, Groq, DeepSeek, Mistral, Together or Cerebras — they're tried as fallbacks.

Search-ready

Dynamic sitemap, robots.txt, IndexNow pings to Bing/Yandex on every publish, Article + Breadcrumb schema, OG tags. Indexed within minutes.

Embed widget

Drop one <script> tag on any site and render your latest posts inline. Useful for boosting other properties you already own.

Self-hosted, free tier

You own your domain, your D1 database, your R2 image bucket. Cloudflare's free tier covers ~10k Workers AI requests a day. No usage-based SaaS pricing.

How it works

  1. Install.

    bash setup.sh creates a Cloudflare Pages project, a D1 database, an R2 bucket, applies the schema, pushes your secrets, and deploys the site. Resumable — if any step fails, just re-run.

  2. Generate.

    A scheduled Worker calls a multi-step chain: pick a topic → generate text → generate hero image → publish → ping IndexNow. Each step is idempotent and short enough to fit inside Cloudflare's request budget.

  3. Distribute.

    New posts appear in your sitemap immediately. IndexNow pings Bing/Yandex/Seznam. Google picks them up via sitemap.xml. RSS feed exposes them to readers and aggregators.

  4. Measure + iterate.

    The admin dashboard shows your queue, published pages, and per-provider stats. Hit the dry-run endpoint to preview what the AI would write before it ever writes to your database.

Install in 5 minutes

git clone https://github.com/Benjamin-Bloch/pages-seo
cd pages-seo
npm install -g wrangler && wrangler login

# pick one — they all do the same thing
bash setup.sh
# or:  python3 setup.py
# or:  node setup.js

The setup script asks for a project name, your domain, and (optionally) keys for any of the 9 AI providers. It generates an admin token, creates all the Cloudflare resources, applies the schema and deploys. If anything fails, just re-run — it resumes from the failed step.

Once it finishes, open https://<your-domain>/admin, paste the admin token, and you're in.

FAQ

How much does it cost?

If you stay on Cloudflare's free tier and use Workers AI, the toolkit itself is free. You're paying $0/month for the infrastructure (Pages + D1 + R2 + Workers AI free quotas) until you exceed the free limits. At that point you're at Cloudflare's $5/month Workers Paid plan plus pennies-per-million on D1/R2/AI.

Do I have to use Workers AI?

No. It's the default because the free tier covers most use cases, but you can plug in OpenAI, Anthropic Claude, Google Gemini, Groq, DeepSeek, Mistral, Together AI or Cerebras — and the toolkit will try them in fallback order. Adding another provider is a single config entry.

What about content quality?

Workers AI (Llama 3.3 70B) produces SEO-coherent but generic copy. It's good enough to rank for long-tail keywords. For premium-feeling content, plug in Claude or GPT-5 — same toolkit, same workflow, just different output.

Will Google penalise AI content?

Google's published position is that AI content is fine if it's helpful to readers. The toolkit ships SEO essentials (schema, structured headings, FAQ blocks, primary/secondary keyword targeting, IndexNow). Quality of output is on the model you choose.

Can I edit posts manually?

Yes. Posts are stored in your D1 database — edit via the admin UI, or run SQL directly with wrangler d1 execute. The hero image lives in R2; replace by uploading a new file with the same key.

Is the admin dashboard secure?

Bearer-token auth with a 64-char hex token generated at install. Stored as a Cloudflare Pages secret on the server, in localStorage on your machine. No accounts, no sessions — rotate the token via wrangler pages secret put ADMIN_TOKEN if it leaks.
